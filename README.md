# Сайт-портфолио психотерапевта Анны Мельниковой

> Премиальный, адаптивный сайт частной психологической практики в Алматы (Казахстан) и онлайн по всему миру.

🌐 **Демо на GitHub Pages:** [https://wateri1.github.io/psychologist-landing/](https://wateri1.github.io/psychologist-landing/)

---

## О проекте

Современный лендинг частного психолога и гештальт-терапевта, ориентированный на клиентов из Казахстана (Алматы) и русскоязычную аудиторию по всему миру:

- **Интерактивный квиз подбора запроса**: мгновенная обратная связь по темам тревоги, выгорания, личных границ, самооценки и кризисов.
- **Интерактивный калькулятор форматов и стоимости**: прозрачные тарифы в казахстанских тенге (₸) с возможностью переключения между разовыми встречами и пакетными курсами (-10%).
- **Блок дипломов и сертификации**: валидация квалификации (МГУ, МИГИП EAGT, EAP, супервизия) с полноэкранным лайтбоксом просмотра сертификатов.
- **Интерактивное бронирование**: модальное окно с выбором темы, формата (онлайн / очно в кабинете на Медеу / Достык) и прямой отправкой в Telegram / WhatsApp.
- **Этика и безопасность**: соблюдение стандартов EAGT, конфиденциальный терапевтический контракт, контакты экстренных горячих линий Казахстана (150, 111).

## Стек технологий

- **HTML5**: семантическая разметка, доступность (ARIA), SEO-оптимизация.
- **Vanilla CSS3**: кастомный дизайн-код (Warm Neutral & Sage Palette), двойные безели (Apple / Notion style), микро-анимации, плавная адаптивность.
- **Vanilla JavaScript**: быстрый, независимый от сторонних тяжелых библиотек код интерактивности (квиз, модалки, фильтры, аккордеон, валидация).
